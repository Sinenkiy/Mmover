# MMover — российская версия для RuStore

## Идентичность и интеграции

Пакет и namespace: `com.divinegames.mmover`. Версия 2.01 / 201. Приложение распространяется только через RuStore: `https://apps.rustore.ru/app/com.divinegames.mmover`. Сохраняйте бренд, иконки, подпись, пользовательские preferences и контакты. Не добавляйте Google Play Billing/Review/Updates.

Реклама: только Yandex Mobile Ads 8.6.0 независимо от региона. Существующие release ID: верхний `demo-banner-yandex`, нижний `R-M-17944676-2`, rewarded `R-M-17944676-3`. Верхний demo ID — исходная настройка, не заменять без задачи пользователя. Debug использует только demo-рекламу. Firebase, AdMob, UMP, медиация и платежи не реализованы. Кнопка отключения рекламы открывает информационный диалог и не выдаёт права.

## Стек и код

Kotlin 2.4.21 через встроенную поддержку AGP 9.4.1 (новый публичный DSL), Gradle 9.6.0; minSdk 24, compileSdk/targetSdk 37, Java 11 и desugaring. Модуль `app`, XML, View Binding, AppCompat, Preference, Material, корутины. Зависимости закреплены в `gradle/libs.versions.toml`.

- `MotionController`, `TaskScheduler`: чистая логика движения, ожидания и остановки. Один callback, монотонное время. `pause_duration` хранит шаги по 5 секунд.
- `ReviewPolicy`/`ReviewController`: нативный RuStore Review 10.5.2 после ручного Стоп; 3 сеанса от 2 минут, 10 минут суммарно, 2 дня. Задержка 1 секунда, отмена при новом старте/другом UI/onPause. Не предлагать оценку в Moving/Waiting или поверх других окон. Повторы через 14/60 дней и 3 новых сеанса, максимум 3 за 365 дней; отказ старого never_show_rating сохраняется. Completion SDK не доказывает оценку, ReviewExists прекращает напоминания; ошибки тихие, без открытия магазина. Состояние review_prompt переживает обновления. Перед/после полноэкранной рекламы — пауза 2 минуты. Ссылка на страницу RuStore в меню открывается только по явному действию пользователя.
- `MainActivity`: отображение состояния, яркость и вибрация. В `onPause` движение останавливается, при возврате само не запускается. В `onDestroy` закрываются контроллеры.
- `RewardAccess`/`RewardAccessController`: календарный доступ, сохранение ISO-даты и флага вместе. Только реальная награда; закрытие или ошибка не дают доступ. Проверка полуночи и смены часов, в фоне очередь отменяется.
- `MainAdsController`: владелец Яндекс SDK, баннеров и rewarded одного экрана. Не переносить в ViewModel. Запросы только в активном lifecycle, блокировка дублей, отбрасывание поздних callbacks, освобождение listeners. Для sticky-баннеров refresh принадлежит SDK; `BannerRefreshController` ограничивает первоначальные запросы. Сроки хранятся в `banner_timing`, исключённом из обоих видов backup.
- `MovingBackgroundView`: Choreographer, работа при animator scale 0/1, загрузка вне UI, отмена и освобождение при detach. Процедурная текстура 240×240, BitmapShader; пять фонов в порядке Помехи, Острова, Плитка, Штрихкод, Лабиринт.
- `MovementDirection`: поворот через каждые 2000 пикселей пути, разделение кадра на границе. Полосы вверх/вниз; остальные поворачиваются минимум на 45°. На новом старте расстояние сбрасывается.
- `PatternPreviewView`: неподвижный preview, одна текстура, отмена предыдущей загрузки и освобождение при detach.
- `MouseMoverApplication`: defaults только при отсутствующих ключах, повторно безопасная миграция удалённых фонов. Новые defaults 10 секунд / 500 пикселей в секунду; существующие настройки не перезаписывать.
- `SettingsActivity`: восстановленный фрагмент сохраняется, возврат с RESULT_OK. `MainActivity` сохраняет bitmap и баннеры, перегружает фон только при смене; смена языка пересоздаёт Main один раз.
- `StartActivity`: версия считается просмотренной только после «Старт»; справка возвращается к существующему Main. `SplashScreenActivity`: 2 секунды после фокуса, отмена при уходе.
- Шапка: 48 dp controls и доставленные insets, без таблиц высоты по API и накопления padding. Не терять чёрный фон и центральный таймер ожидания.

## Проверки

Из корня проекта: `./gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug`. При изменении ресурсов/SDK/R8 также `:app:assembleRelease`. Сборка unsigned release не доказывает работу подписанного приложения.

Основная матрица переноса: API 25, 28, 32, 36; для targetSdk 37 также API 37 (MMover_API_37, Google APIs x86_64). Android-тесты используют Espresso 3.7.0 / AndroidX JUnit 1.3.0: Espresso 3.6.1 несовместим с UI-вводом на Android 17. Запускать тяжёлые AVD последовательно, предпочтительно с `-read-only -no-snapshot`. Не очищать данные пользовательского устройства. Сохранять и восстанавливать временные настройки. Обычные Android-тесты блокируют рекламу через политику запросов до RESUMED. Сетевые тесты отдельно, только demo ID, без автоматических кликов по рабочим объявлениям.

Сохраняйте EN/RU/DE/FR, соответствие массивов и placeholders. Проверяйте маленький экран, планшет, светлую/тёмную тему, крупный шрифт, смену языка, повторные insets. Физическая мышь проверяется отдельно от эмулятора.

План и фактические результаты переноса: `PORTING_PROGRESS.md`; требования: `PORTING_GUIDE_RU.md`. Эталон `C:\Users\antro\AndroidStudioProjects\MouseMover` — только для чтения, включая незакоммиченные файлы; не использовать результаты его тестов как результаты MMover.

Тестовый harness: для непрерывно рисующего Main используйте onFrameActivity и явные ограниченные ожидания состояния, чтобы off-thread ActivityScenario.onActivity не ожидал idle кадрового цикла. Сетевые тесты opt-in: liveYandex=true, livePlayback=true; у demo SDK кнопка закрытия может не иметь accessibility-подписи и потребовать визуального закрытия. Memory profile включается memoryProfile=true, с demo SDK — также memoryAds=true.
